# docs/

Documentación técnica del proyecto PrimeLux SmartShop.

## Estructura

- `architecture/` — decisiones de arquitectura y elección del stack tecnológico
- `database/` — esquema SQL, diccionario de datos y modelo relacional
- `decisions/` — decisiones puntuales tomadas durante el desarrollo
- `designs/` — mockups y diseños de cada pantalla de la aplicación
- `memory/` — borradores de la memoria del proyecto
